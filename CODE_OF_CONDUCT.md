# Code of Conduct

We want AskMyModel to be a welcoming, respectful project for everyone.

Be considerate, constructive, and patient. Critique ideas and code without personal attacks. Do not publish harassment, discriminatory content, threats, private information, or other abusive material.

Project maintainers may edit or remove content that violates these expectations and may restrict participation when needed. To report a concern privately, use the contact route in [SECURITY.md](SECURITY.md).
