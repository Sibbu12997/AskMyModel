# Security policy

Please do not report security vulnerabilities in public issues. Use GitHub's private vulnerability reporting for this repository, if enabled, or contact the maintainers through the repository owner’s GitHub profile.

Include the affected version, impact, and steps to reproduce. Do not include real credentials, PBIX files, customer data, or unredacted model metadata.

AskMyModel is a local development tool. Its bridge binds to `127.0.0.1`; keep it local and do not expose it to a network or the public internet without first adding authentication and reviewing the security model.
